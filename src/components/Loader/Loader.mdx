## Overview

Loaders provide visual feedback to users when content is being processed, fetched, or loaded. They help maintain user engagement during wait times and provide clear indication that the system is working. Our Loader component offers multiple animation types, sizes, and styling options to fit various use cases.

## Accessibility

Our Loader component follows accessibility best practices:

- **Semantic HTML**: Uses proper `role="status"` to indicate loading state to assistive technologies
- **ARIA Support**: Provides appropriate `aria-label` and `aria-live` attributes for screen readers
- **Visual Indicators**: Uses animation and color to convey loading state visually
- **Motion Preferences**: Respects user's motion preferences with `prefers-reduced-motion`
- **Screen Reader Friendly**: Announces loading states and completion to assistive technologies
- **Color Accessibility**: Ensures sufficient contrast ratios across all variants

## Best Practices

### Do's ✅

- Use clear, descriptive labels (e.g., "Loading content..." instead of just "Loading")
- Use the `color` prop for brand-specific colors or custom theming
- Choose appropriate animation speeds for expected load times
- Provide context about what's being loaded when possible
- Use consistent loader types throughout your application
- Consider using skeleton screens for longer loading times

### Don'ts ❌

- Don't use loaders for operations that complete in under 200ms
- Avoid overusing animated loaders in dense interfaces
- Don't rely solely on animation to convey loading state
- Don't make loaders too small to be noticed (minimum 16px recommended)
- Don't use multiple different loader types in the same interface
- Avoid using overly bright or distracting colors for loaders

### Loader Combinations

```jsx
// Quick operations (< 1 second)
<Loader size="sm" type="spinner" />

// Medium operations (1-5 seconds)
<Loader size="md" type="dots" label="Processing..." />

// Long operations (> 5 seconds)
<Loader size="lg" type="wave" label="This may take a moment..." />

// Custom branded loaders
<Loader color="#10b981" type="spinner" label="Success loading..." />
<Loader color="#f59e0b" type="pulse" label="Warning state..." />
```
