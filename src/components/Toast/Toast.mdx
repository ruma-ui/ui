## Overview

Toast notifications provide brief feedback about actions or events. They appear temporarily and automatically dismiss to keep users informed without interrupting their workflow. Our Toast component is designed to be accessible, customizable, and consistent with the design system.

### Toast `variant`

The `variant` prop determines the visual style and semantic meaning of the toast. Each variant includes appropriate colors and icons.

```jsx
<Toast variant="success" title="Success!" description="Operation completed." />
<Toast variant="error" title="Error" description="Something went wrong." />
<Toast variant="warning" title="Warning" description="Please check your input." />
<Toast variant="info" title="Info" description="Here's some information." />
```

### Toast `duration`

The `duration` prop sets the auto-dismiss delay in milliseconds. Set to `0` to disable auto-dismiss.

```jsx
<Toast duration={3000} title="Quick" description="Dismisses after 3 seconds." />
<Toast duration={10000} title="Slow" description="Dismisses after 10 seconds." />
<Toast duration={0} title="Persistent" description="Never auto-dismisses." />
```

### Toast `title` and `description`

The `title` and `description` props provide the main content of the toast.

```jsx
<Toast
    title="Toast Title"
    description="This is the description that provides more details about the toast content."
/>
```

### Toast `children`

The `children` prop allows you to provide custom JSX content instead of using `title` and `description`.

```jsx
<Toast>
    <div>
        <strong>Custom Content</strong>
        <p>You can use any JSX here.</p>
        <Button size="sm">Action</Button>
    </div>
</Toast>
```

### Toast `showCloseButton`

The `showCloseButton` prop controls whether the close button is displayed.

```jsx
<Toast showCloseButton={false} title="No Close Button" description="This toast has no close button." />
<Toast showCloseButton={true} title="With Close Button" description="This toast has a close button." />
```

### Toast `animation`

The `animation` prop enables or disables enter/exit animations.

```jsx
<Toast animation={true} title="Animated" description="This toast animates in and out." />
<Toast animation={false} title="No Animation" description="This toast appears instantly." />
```

### Toast `className`

The `className` prop allows you to add custom styling.

```jsx
<Toast
    className="border-2 border-dashed border-purple-400"
    title="Custom Styled"
    description="This toast has custom border styling."
/>
```

## Accessibility

Our Toast component follows accessibility best practices:

- **Semantic HTML**: Uses proper ARIA attributes for screen readers
- **Live Regions**: Uses `aria-live="assertive"` for important notifications
- **Keyboard Navigation**: Close button is keyboard accessible
- **Screen Reader Support**: Proper labeling with `aria-label` and `aria-describedby`
- **Focus Management**: Close button receives focus when toast appears
- **Color Contrast**: All variants meet WCAG color contrast requirements
- **Motion Preferences**: Respects user's motion preferences for animations

## Best Practices

### Do's ✅

- Use toasts for brief, non-critical information
- Keep messages clear and concise
- Use appropriate variants for semantic meaning
- Position toasts where they won't interfere with content
- Allow manual dismissal for important notifications
- Test with screen readers for accessibility

### Don'ts ❌

- Don't use for critical errors that require immediate action
- Avoid long messages that require scrolling
- Don't stack too many toasts simultaneously
- Don't rely solely on color to convey meaning
- Avoid using toasts for form validation errors

### Toast Usage Guidelines

```jsx
// Good: Success confirmation
<Toast variant="success" title="Saved!" description="Your changes have been saved." />

// Good: Error notification
<Toast variant="error" title="Upload Failed" description="Please check your file and try again." />

// Good: Warning alert
<Toast variant="warning" title="Session Expiring" description="Your session will expire in 5 minutes." />

// Avoid: Critical action required
// Use a modal or inline error instead
<Toast variant="error" title="Payment Failed" description="Click here to retry payment." />
```

### Implementation Example

```jsx
import { useState } from "react";
import { Toast } from "./Toast";

function App() {
    const [toast, setToast] = useState({
        open: false,
        variant: "success",
        title: "",
        description: "",
    });

    const showToast = (variant, title, description) => {
        setToast({ open: true, variant, title, description });
    };

    const handleClose = () => {
        setToast((prev) => ({ ...prev, open: false }));
    };

    return (
        <div>
            <button onClick={() => showToast("success", "Success!", "Operation completed.")}>
                Show Success Toast
            </button>

            <Toast
                open={toast.open}
                onClose={handleClose}
                variant={toast.variant}
                title={toast.title}
                description={toast.description}
            />
        </div>
    );
}
```
