## Overview

The Drawer component is a sliding panel that provides a focused interaction layer from any edge of the screen. Built with comprehensive keyboard navigation, proper focus management, and ARIA attributes for production-ready applications.

<Canvas of={DrawerStories.RightDrawer} />

## Positions

### Right Position

The right position is the default and slides in from the right side. It's commonly used for secondary content, settings panels, or additional information.

<Canvas of={DrawerStories.RightDrawer} />

### Left Position

The left position slides in from the left side. Perfect for main navigation menus, sidebar content, or primary navigation interfaces.

<Canvas of={DrawerStories.LeftDrawer} />

### Top Position

The top position slides down from the top of the screen. Useful for notifications, alerts, or dropdown-style interfaces that need to grab attention.

<Canvas of={DrawerStories.TopDrawer} />

### Bottom Position

The bottom position slides up from the bottom. Great for mobile-style interfaces, action sheets, or content that should feel grounded.

<Canvas of={DrawerStories.BottomDrawer} />

### Drawer `position`

The `position` prop determines which edge of the screen the drawer slides in from. Choose the appropriate position based on the drawer&apos;s purpose and user context.

```jsx
<Drawer position="left" open={true} onClose={handleClose} title="Left Drawer">
  Left drawer content
</Drawer>
<Drawer position="right" open={true} onClose={handleClose} title="Right Drawer">
  Right drawer content
</Drawer>
<Drawer position="top" open={true} onClose={handleClose} title="Top Drawer">
  Top drawer content
</Drawer>
<Drawer position="bottom" open={true} onClose={handleClose} title="Bottom Drawer">
  Bottom drawer content
</Drawer>
```

## Accessibility

The Drawer component follows WAI-ARIA guidelines and includes comprehensive accessibility features:

- **Focus Management**: Automatic focus to drawer on open and return focus on close
- **Focus Trap**: Keyboard navigation stays within the drawer when open
- **Keyboard Navigation**: Full support for Escape key closing and Tab navigation
- **Screen Reader Support**: Proper ARIA attributes including role, aria-modal, and aria-labelledby
- **Overlay Interaction**: Configurable overlay click behavior for different use cases

## Best Practices

### When to Use

- **Navigation**: For main navigation menus or sidebar content
- **Secondary Content**: When you need to show additional information without leaving the main context
- **Forms and Settings**: For focused data entry or configuration interfaces
- **Filters and Search**: When users need to apply complex filters or search criteria
- **Mobile Interfaces**: For bottom drawers that feel natural on touch devices

### When Not to Use

- **Primary Content**: Don&apos;t hide essential content behind a drawer
- **Simple Messages**: Consider toast notifications for brief status messages
- **Full Page Content**: Use regular pages for content that needs the full viewport
- **Frequent Actions**: Avoid drawers for actions users perform repeatedly

### Guidelines

1. **Clear Purpose**: Every drawer should have a specific, obvious purpose
2. **Position Matters**: Choose the position based on the drawer&apos;s relationship to content
3. **Obvious Exit**: Always provide clear ways to close the drawer
4. **Responsive Design**: Ensure drawers work well on all screen sizes
5. **Performance**: Use drawers judiciously to avoid degrading page performance
6. **Accessibility**: Always provide proper ARIA labels and keyboard navigation

### Content Guidelines

1. **Concise Titles**: Use clear, descriptive titles that explain the drawer&apos;s purpose
2. **Actionable Language**: Use specific, actionable language for buttons and calls-to-action
3. **Error Handling**: Provide clear error states and recovery options within drawers
4. **Loading States**: Show appropriate loading indicators for async operations
5. **Mobile Optimization**: Design drawer content that works well on touch devices

### Position Guidelines

1. **Left Drawers**: Best for main navigation, primary content, or persistent sidebars
2. **Right Drawers**: Ideal for secondary content, settings, filters, or additional information
3. **Top Drawers**: Perfect for notifications, alerts, or content that needs attention
4. **Bottom Drawers**: Great for mobile actions, confirmations, or grounded content
