## Overview

The Image component provides optimized image rendering with Next.js Image component, offering automatic optimization, lazy loading, and responsive behavior. It supports various aspect ratios, fit options, and styling to maintain consistency with our design system.

**Note:** This component is optimized for Next.js applications. For React applications, consider using the standard `<img>` tag or a custom image component.

### Image `src` and `alt`

The `src` prop specifies the image source URL, and `alt` provides alternative text for accessibility and when the image fails to load.

```jsx
<Image src="https://example.com/image.jpg" alt="Description of the image" />
```

<Unstyled>
    <Image src="https://picsum.photos/200/150" alt="Sample image" width={200} height={150} />
</Unstyled>

### Image `width` and `height`

Specify the dimensions of the image. These are required for Next.js Image optimization unless using the `fill` prop.

```jsx
<Image src="https://picsum.photos/400/300" alt="Landscape image" width={400} height={300} />
<Image src="https://picsum.photos/300/300" alt="Square image" width={300} height={300} />
```

### Image `fill`

The `fill` prop makes the image fill its parent container, useful for responsive designs. When using `fill`, the parent container must have `position: relative`.

```jsx
<div style={{ position: "relative", width: "300px", height: "200px" }}>
    <Image fill src="https://picsum.photos/1200/800" alt="Filling container" />
</div>
```

### Image `fallback`

The `fallback` prop allows you to specify custom content to display when the image fails to load.

```jsx
<Image
    src="https://invalid-url.com/image.jpg"
    alt="With fallback"
    width={300}
    height={300}
    fallback={
        <div className="flex h-full w-full items-center justify-center bg-gray-100 text-gray-500">
            Image not available
        </div>
    }
/>
```

## Accessibility

Our Image component follows accessibility best practices:

- **Alt Text**: Always provide meaningful alternative text for screen readers
- **Semantic HTML**: Uses proper `<img>` elements with Next.js optimization
- **Loading Optimization**: Automatic lazy loading and responsive images
- **Error Handling**: Graceful fallback when images fail to load
- **Keyboard Navigation**: No keyboard interaction needed for images

## Best Practices

### Do's ✅

- Always provide descriptive `alt` text for accessibility
- Use appropriate aspect ratios for different content types
- Optimize image file sizes for web performance
- Use `fill` prop for responsive container filling
- Choose fit options that preserve important image content
- Use `showSkeleton` for better loading experience
- Provide meaningful `fallback` content for error states
- Use `skeletonVariant="circle"` for profile images
- Combine skeleton and fallback for comprehensive UX

### Don'ts ❌

- Don't omit `alt` text unless the image is purely decorative
- Avoid using `fill` without a positioned parent container
- Don't rely on images alone to convey critical information
- Avoid extremely high-resolution images that impact performance
- Don't use skeleton without considering the aspect ratio
- Avoid generic fallback messages; make them contextual

### Usage Examples

```jsx
// Profile avatar with skeleton and fallback
<Image
  src="/avatar.jpg"
  alt="User profile picture"
  width={100}
  height={100}
  rounded="full"
  aspectRatio="square"
  showSkeleton
  skeletonVariant="circle"
  fallback={
    <div className="flex items-center justify-center w-full h-full bg-gray-200 text-gray-500 text-2xl">
      👤
    </div>
  }
/>

// Hero banner with skeleton loading
<Image
  src="/hero.jpg"
  alt="Company hero image"
  width={1200}
  height={600}
  fit="cover"
  aspectRatio="wide"
  showSkeleton
  skeletonAnimation="wave"
/>

// Product thumbnail with error handling
<Image
  src="/product.jpg"
  alt="Product image"
  width={300}
  height={300}
  fit="contain"
  rounded="md"
  className="shadow-md"
  showSkeleton
  fallback={
    <div className="flex flex-col items-center justify-center w-full h-full bg-gray-50 text-gray-400 p-4 text-center">
      <div className="text-3xl mb-2">📦</div>
      <div className="text-sm">Image unavailable</div>
    </div>
  }
/>
```
