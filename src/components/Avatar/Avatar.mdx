## Overview

The Avatar component displays user profile images, initials, or fallback icons in a consistent, accessible format. Built with proper image loading states, status indicators, and keyboard navigation for production-ready applications.

The `variant` prop determines the visual style and border treatment of the avatar. Choose the appropriate variant based on the avatar's context and importance.


## Accessibility

The Avatar component follows accessibility best practices and includes:

- **Image Alt Text**: Proper alt text for screen readers when using images
- **Keyboard Navigation**: Full keyboard support for clickable avatars
- **Focus Management**: Clear focus indicators and proper focus handling
- **Status Indicators**: Accessible labels for status indicators
- **Semantic HTML**: Proper button roles for interactive avatars

## Best Practices

### When to Use

- **User Identification**: For displaying user profile pictures in interfaces
- **Team Members**: In team lists, collaboration tools, or member directories
- **Comments/Posts**: To identify authors in content feeds or discussions
- **Navigation**: As profile triggers in headers or navigation menus

### When Not to Use

- **Decorative Images**: Use regular img elements for non-profile imagery
- **Large Images**: Consider dedicated image components for hero images or galleries
- **Complex Graphics**: Use appropriate image components for detailed graphics

### Guidelines

1. **Consistent Sizing**: Use consistent avatar sizes within the same interface context
2. **Meaningful Fallbacks**: Provide initials or meaningful fallback content
3. **Proper Alt Text**: Always include descriptive alt text for accessibility
4. **Status Clarity**: Use status indicators consistently across your application
5. **Loading States**: Handle image loading gracefully with appropriate fallbacks
6. **Performance**: Optimize avatar images for web delivery and consider lazy loading

### Content Guidelines

1. **Image Quality**: Use high-quality, well-cropped profile images
2. **Consistent Aspect**: Ensure all avatar images have consistent aspect ratios
3. **Appropriate Content**: Use professional, appropriate images for business contexts
4. **Fallback Strategy**: Always provide meaningful initials or fallback content
5. **Status Accuracy**: Keep status indicators accurate and up-to-date
