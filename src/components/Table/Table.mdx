## Overview

The Table component renders tabular data with production-grade features like sticky headers, zebra striping, outlined borders, and configurable density. It supports custom accessors, alignment, sticky columns, and responsive scrolling.

### Table with sticky header and max height


### Table `rowClassName` and `cellClassName`

Apply conditional styling based on row or cell data.

```jsx
<Table
    rowClassName={(row, index) => (row.status === "completed" ? "bg-green-50" : "")}
    cellClassName={(row, column) =>
        column.key === "score" && row.score > 80 ? "font-bold text-green-700" : ""
    }
/>
```

<Unstyled>
    <Table
        columns={[
            { key: "name", header: "Project" },
            { key: "status", header: "Status" },
            { key: "score", header: "Score", align: "right" },
        ]}
        data={[
            { name: "Project Alpha", status: "completed", score: 95 },
            { name: "Project Beta", status: "in-progress", score: 67 },
            { name: "Project Gamma", status: "failed", score: 23 },
        ]}
        rowClassName={(row) =>
            row.status === "completed" ? "bg-green-50" : row.status === "failed" ? "bg-red-50" : ""
        }
        cellClassName={(row, column) =>
            column.key === "score" && row.score > 80 ? "font-bold text-green-700" : ""
        }
    />
</Unstyled>

## Accessibility

- **Keyboard navigation**: Full keyboard support for interactive elements
- **Screen readers**: Proper table semantics with captions and headers
- **Focus management**: Visible focus indicators for resizable columns
- **ARIA**: Appropriate roles and labels for complex interactions

## Best Practices

- **Use captions**: Always provide `caption` or `ariaLabel` for accessibility
- **Appropriate density**: Choose density based on content and available space
- **Virtualization**: Enable for datasets with 100+ rows for better performance
- **Sticky headers**: Use with `maxHeight` for long scrollable tables
- **Column widths**: Set explicit widths when using sticky columns or resizing
