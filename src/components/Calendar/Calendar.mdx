# Calendar

[Source code](https://github.com/ruma-ui/ui/tree/main/src/components/Calendar)

## Overview

The Calendar component is a lightweight, fully controlled/uncontrolled date picker grid built with date-fns. It supports month navigation, single-day selection, min/max range limits, and custom disabling logic.

### Usage

```tsx
import { useState } from "react";
import { Calendar } from "@/components";

export function Example() {
    const [selected, setSelected] = useState<Date | null>(new Date());
    return (
        <Calendar
            selectedDate={selected}
            onDateSelect={setSelected}
            weekStartsOn={0}
            showOutsideDays
            showMonthYearPickers
        />
    );
}
```

### Accessibility

- **Keyboard focus**: Day buttons are focusable and expose `aria-selected` and `aria-disabled`.
- **Semantics**: Markup uses grid semantics and accessible labels for month navigation.
- **Live region**: The visible month label is announced when it changes.

### Animations

- Uses Tailwind CSS animate classes for subtle slide + fade between months.
- Toggle with `disableAnimation` (default: `false`). Set to `true` to disable transitions.

### Best Practices

- **Min/Max**: Use `minDate`/`maxDate` to restrict selectable dates.
- **Disabled logic**: Provide `isDateDisabled` to exclude custom holidays or blackout dates.
- **Controlled month**: Use `month` and `onMonthChange` when syncing the visible month with parent state.
- **Localization**: Pass a `date-fns` locale for localized month and weekday labels.
