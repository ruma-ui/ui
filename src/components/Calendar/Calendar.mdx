## Overview

A lightweight, accessible calendar component with keyboard-friendly navigation, controllable month, and configurable min/max date constraints. Designed to integrate with form inputs like DatePicker.

### Calendar `minDate`, `maxDate`, and `isDateDisabled`

Use these to limit selection and disable specific dates.

```jsx
const today = new Date();
const min = new Date(today.getFullYear(), today.getMonth(), 5);
const max = new Date(today.getFullYear(), today.getMonth(), 25);

<Calendar
    selectedDate={today}
    onDateSelect={() => {}}
    minDate={min}
    maxDate={max}
    isDateDisabled={(d) => d.getDay() === 0} // disable Sundays
/>;
```

<Unstyled>
    {(() => {
        const today = new Date();
        const min = new Date(today.getFullYear(), today.getMonth(), 5);
        const max = new Date(today.getFullYear(), today.getMonth(), 25);
        return (
            <Calendar
                selectedDate={today}
                onDateSelect={() => {}}
                minDate={min}
                maxDate={max}
                isDateDisabled={(d) => d.getDay() === 0}
            />
        );
    })()}
</Unstyled>

## Accessibility

- **Semantic roles**: Uses appropriate roles for grid and grid cells
- **Keyboard navigation**: Arrow keys for navigation, Escape to exit popovers (when embedded)
- **Focus management**: Clear focus outlines and logical tab order
- **Announcements**: Month/year label uses polite updates

## Best Practices

- **Pair with inputs**: Combine with DatePicker for direct text entry + visual selection
- **Respect constraints**: Always pass `minDate`/`maxDate` when business rules apply
- **Localization**: Set `weekStartsOn` and `locale` for your audience
- **Consistent size**: Keep calendar size consistent across screens for predictability
