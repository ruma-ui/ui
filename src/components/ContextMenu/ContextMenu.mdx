## Overview

The ContextMenu component provides a right-click context menu with intelligent positioning that adapts to viewport boundaries. It follows the same design system as other menu components but is specifically designed for contextual actions triggered by right-clicking on content areas.

## Basic Usage

The ContextMenu uses a compound pattern similar to the Dropdown component. The `ContextMenu` provides context, `ContextMenuTrigger` wraps the area that responds to right-clicks, and `ContextMenuContent` contains the menu items.

```tsx
<ContextMenu>
    <ContextMenuTrigger>
        <div>Right-click this area</div>
    </ContextMenuTrigger>
    <ContextMenuContent>
        <ContextMenuLabel>Actions</ContextMenuLabel>
        <ContextMenuSeparator />
        <ContextMenuGroup>
            <ContextMenuItem>
                <FaCopy className="mr-2 h-4 w-4" />
                <span>Copy</span>
            </ContextMenuItem>
            <ContextMenuItem>
                <FaPaste className="mr-2 h-4 w-4" />
                <span>Paste</span>
            </ContextMenuItem>
            <ContextMenuItem>
                <FaCut className="mr-2 h-4 w-4" />
                <span>Cut</span>
            </ContextMenuItem>
        </ContextMenuGroup>
    </ContextMenuContent>
</ContextMenu>
```

## Component API

<ArgTypes of={ContextMenuStories} />

### ContextMenu

The root component that provides context for the context menu.

```tsx
<ContextMenu open={open} onOpenChange={setOpen}>
    {/* children */}
</ContextMenu>
```

**Props:**

- `children`: ReactNode - The context menu content
- `open?`: boolean - Controlled open state
- `defaultOpen?`: boolean - Default open state
- `onOpenChange?`: (open: boolean) => void - Callback when open state changes

### ContextMenuTrigger

The trigger area that responds to right-click events.

```tsx
<ContextMenuTrigger disabled={false}>
    <div>Right-clickable area</div>
</ContextMenuTrigger>
```

**Props:**

- `children`: ReactNode - The trigger area content
- `disabled?`: boolean - Whether the context menu is disabled

### ContextMenuContent

The content container for the context menu with intelligent positioning.

```tsx
<ContextMenuContent className="w-56">{/* menu items */}</ContextMenuContent>
```

**Props:**

- `children`: ReactNode - The menu content
- `className?`: string - Additional CSS classes

### ContextMenuItem

An interactive menu item.

```tsx
<ContextMenuItem onSelect={handleSelect}>
    <FaCopy className="mr-2 h-4 w-4" />
    <span>Copy</span>
</ContextMenuItem>
```

**Props:**

- `children`: ReactNode - The item content
- `disabled?`: boolean - Whether the item is disabled
- `onSelect?`: () => void - Callback when item is selected
- All standard button HTML attributes

### ContextMenuLabel

A non-interactive label for grouping menu items.

```tsx
<ContextMenuLabel>Actions</ContextMenuLabel>
```

**Props:**

- `children`: ReactNode - The label text

### ContextMenuSeparator

A visual separator between menu sections.

```tsx
<ContextMenuSeparator />
```

**Props:**

- `className?`: string - Additional CSS classes

### ContextMenuGroup

A grouping container for menu items.

```tsx
<ContextMenuGroup>
    <ContextMenuItem>Item 1</ContextMenuItem>
    <ContextMenuItem>Item 2</ContextMenuItem>
</ContextMenuGroup>
```

**Props:**

- `children`: ReactNode - The grouped content

## Accessibility

The ContextMenu component follows WAI-ARIA guidelines and includes comprehensive accessibility features:

- **Keyboard Navigation**: Full keyboard support with Escape key to close
- **Screen Reader Support**: Proper ARIA attributes and role definitions
- **Focus Management**: Clear focus indicators and logical focus flow
- **Right-Click Handling**: Prevents default browser context menu and provides custom behavior
- **Viewport Awareness**: Automatically adjusts position to stay within viewport boundaries

## Best Practices

### When to Use

- **Contextual Actions**: For actions that are relevant to specific content or selections
- **Text Editors**: For text manipulation actions like copy, paste, cut
- **File Managers**: For file operations like rename, delete, properties
- **Image Galleries**: For image-specific actions like view, edit, download
- **Data Tables**: For row or cell-specific actions
- **Canvas/Drawing Apps**: For tool selection and object manipulation

### When Not to Use

- **Primary Navigation**: Use regular menus or dropdowns for main navigation
- **Form Actions**: Use buttons for primary form actions
- **Global Actions**: Use toolbar buttons for actions available everywhere
- **Simple Actions**: Use regular buttons for single, always-available actions

### Guidelines

1. **Context Relevance**: Only show actions that make sense for the current context
2. **Consistent Actions**: Use similar actions across similar contexts for predictability
3. **Progressive Disclosure**: Don't overwhelm users with too many options
4. **Visual Feedback**: Clearly indicate right-clickable areas
5. **Positioning**: The component handles positioning automatically, but test edge cases
6. **Performance**: For dynamic content, consider lazy loading for large menus

### Implementation Tips

- **Prevent Default**: The component automatically prevents the browser's default context menu
- **Multiple Menus**: You can have multiple context menus on the same page for different areas
- **Nested Triggers**: Be careful with nested trigger areas to avoid conflicts
- **Mobile Considerations**: Context menus work on mobile but consider touch interactions
- **Selection Context**: Use the context menu position to determine relevant actions based on selection
