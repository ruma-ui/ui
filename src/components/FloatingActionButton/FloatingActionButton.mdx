## Overview

Floating Action Buttons (FABs) are circular buttons that float above the UI and perform the primary action in an application. They are typically used for prominent actions like creating new content, sharing, or accessing key features. Our FloatingActionButton component is designed to be highly visible, accessible, and customizable with multiple variants, positioning options, and support for multiple actions.

## Variants

### Primary Variant

The primary FAB is used for the most important action on a screen. It should be used sparingly—typically only one primary FAB per screen to avoid confusion about the primary action.

<Canvas of={FloatingActionButtonStories.Primary} />

### Secondary Variant

Secondary FABs are used for important but less critical actions. They work well alongside primary FABs or when you need multiple floating actions.

<Canvas of={FloatingActionButtonStories.Secondary} />

### Tertiary Variant

Tertiary FABs are subtle and work well for less important actions or in interfaces where you need to minimize visual weight while maintaining accessibility.

<Canvas of={FloatingActionButtonStories.Tertiary} />

### Destructive Variant

Use destructive FABs for actions that delete, remove, or cause irreversible changes. The red color provides a clear visual cue about the potentially harmful nature of the action.

## Component API

<ArgTypes of={FloatingActionButton} />

### FloatingActionButton `variant`

The `variant` prop determines the visual style and hierarchy of the FAB. Choose the appropriate variant based on the action's importance and context.

```jsx
<FloatingActionButton variant="primary" icon={<PlusIcon />} />
<FloatingActionButton variant="secondary" icon={<EditIcon />} />
<FloatingActionButton variant="tertiary" icon={<ShareIcon />} />
<FloatingActionButton variant="destructive" icon={<TrashIcon />} />
```

### FloatingActionButton `size`

The `size` prop controls the FAB's dimensions. Choose sizes based on the interface context and action importance.

```jsx
<FloatingActionButton size="sm" icon={<PlusIcon />} />
<FloatingActionButton size="md" icon={<PlusIcon />} />
<FloatingActionButton size="lg" icon={<PlusIcon />} />
<FloatingActionButton size="xl" icon={<PlusIcon />} />
```

### FloatingActionButton `position`

The `position` prop controls where the FAB appears on the screen. Choose positions that don't interfere with other important UI elements.

```jsx
<FloatingActionButton position="bottom-right" icon={<PlusIcon />} />
<FloatingActionButton position="bottom-left" icon={<PlusIcon />} />
<FloatingActionButton position="top-right" icon={<PlusIcon />} />
<FloatingActionButton position="top-left" icon={<PlusIcon />} />
```

### FloatingActionButton `icon`

The `icon` prop is required and accepts any React element. Use clear, recognizable icons that represent the action being performed.

```jsx
<FloatingActionButton icon={<PlusIcon />} />
<FloatingActionButton icon={<EditIcon />} />
<FloatingActionButton icon={<ShareIcon />} />
<FloatingActionButton icon={<TrashIcon />} />
```

### FloatingActionButton `actions`

The `actions` prop accepts an array of action objects to display multiple actions. When provided, clicking the main FAB toggles the visibility of these actions.

```jsx
<FloatingActionButton
    icon={<PlusIcon />}
    actions={[
        {
            id: "edit",
            icon: <EditIcon />,
            tooltip: "Edit item",
            onClick: () => handleEdit(),
            variant: "secondary",
        },
        {
            id: "share",
            icon: <ShareIcon />,
            tooltip: "Share item",
            onClick: () => handleShare(),
            variant: "tertiary",
        },
        {
            id: "delete",
            icon: <TrashIcon />,
            tooltip: "Delete item",
            onClick: () => handleDelete(),
            variant: "destructive",
        },
    ]}
/>
```

### FloatingActionButton `loading`

The `loading` prop shows a spinner and disables the FAB during asynchronous operations. This prevents duplicate submissions and provides clear feedback.

```jsx
<FloatingActionButton loading icon={<PlusIcon />} />
<FloatingActionButton loading variant="secondary" icon={<EditIcon />} />
```

### FloatingActionButton `animation`

Add subtle animation effects to enhance user interactions and provide visual feedback. These animations are designed to improve usability and user experience.

```jsx
<FloatingActionButton animation="none" icon={<PlusIcon />} />
<FloatingActionButton animation="scale" icon={<PlusIcon />} />
<FloatingActionButton animation="glow" icon={<PlusIcon />} />
<FloatingActionButton animation="lift" icon={<PlusIcon />} />
<FloatingActionButton animation="ripple" icon={<PlusIcon />} />
<FloatingActionButton animation="press" icon={<PlusIcon />} />
```

**Animation Guide:**

- **Scale**: Slightly enlarges on hover, shrinks on click - great for primary actions
- **Glow**: Adds a colored shadow glow - draws attention to important buttons
- **Lift**: Combines upward movement with shadow - modern Material Design feel
- **Ripple**: Creates a ripple effect overlay - excellent user feedback
- **Press**: Only animates on click - minimal but responsive feel

### FloatingActionButton `tooltip` and `showTooltip`

Tooltips provide additional context for FAB actions. The `tooltip` prop sets the text, and `showTooltip` controls visibility.

```jsx
<FloatingActionButton
  icon={<PlusIcon />}
  tooltip="Add new item"
  showTooltip={true}
/>
<FloatingActionButton
  icon={<EditIcon />}
  tooltip="Edit selected item"
  showTooltip={true}
  position="bottom-left"
/>
```

### FloatingActionButton `rounded`

Control the border radius of the FAB to match your design system's aesthetic.

```jsx
<FloatingActionButton rounded="full" icon={<PlusIcon />} />
<FloatingActionButton rounded="xl" icon={<PlusIcon />} />
<FloatingActionButton rounded="lg" icon={<PlusIcon />} />
```

The `className` prop allows you to add custom styling while preserving the component's built-in styles. This is useful for adding custom colors, spacing, or other design elements.

```jsx
<FloatingActionButton

/>

  icon={<PlusIcon />}
/>
```

## Accessibility

Our FloatingActionButton component follows accessibility best practices:

- **Semantic HTML**: Uses proper `<button>` elements with correct ARIA attributes
- **Keyboard Navigation**: Full support for Enter and Space key activation
- **Screen Reader Support**: Proper labeling with `aria-label` and `aria-busy`
- **Focus Management**: Clear focus indicators and logical tab order
- **Loading States**: Communicated to assistive technologies via `aria-busy`
- **Disabled States**: Properly communicated via `aria-disabled` and `disabled` attributes
- **Tooltip Support**: Accessible tooltips with proper ARIA attributes
- **Multiple Actions**: Proper ARIA attributes for expanded/collapsed states

## Best Practices

### Do's ✅

- Use FABs sparingly—typically only one primary FAB per screen
- Choose clear, recognizable icons that represent the action
- Position FABs to avoid interfering with other important UI elements
- Use tooltips when the icon meaning might not be obvious
- Maintain consistent positioning across your application
- Use loading states for operations that take time
- Ensure adequate spacing between multiple FABs (if used)
- Use appropriate variants based on action importance
- Limit multiple actions to 3-4 for better usability

### Don'ts ❌

- Don't use more than 2-3 FABs on a single screen
- Avoid vague or ambiguous icons
- Don't place FABs over important content or navigation
- Don't rely solely on color to convey meaning
- Avoid using FABs for destructive actions without clear visual cues
- Don't make FABs too small (minimum 40px for touch targets)
- Don't use FABs for secondary or tertiary actions when regular buttons would suffice
- Don't overload with too many actions (keep it to essential actions only)

### FAB Combinations

```jsx
// Single primary FAB (recommended)
<FloatingActionButton
  variant="primary"
  icon={<PlusIcon />}
  tooltip="Add new item"
  showTooltip={true}
/>

// Multiple actions FAB
<FloatingActionButton
  icon={<PlusIcon />}
  actions={[
    { id: "edit", icon: <EditIcon />, tooltip: "Edit", onClick: handleEdit },
    { id: "share", icon: <ShareIcon />, tooltip: "Share", onClick: handleShare },
    { id: "delete", icon: <TrashIcon />, tooltip: "Delete", onClick: handleDelete, variant: "destructive" },
  ]}
/>

// FAB with extended functionality
<FloatingActionButton
  variant="primary"
  size="lg"
  icon={<PlusIcon />}
  tooltip="Create new document"
  showTooltip={true}
  animation="lift"
/>
```

### Positioning Guidelines

- **Bottom-right**: Most common position, follows Material Design guidelines
- **Bottom-left**: Good for right-to-left languages or when avoiding conflicts with other UI
- **Top-right**: Useful when bottom space is occupied by navigation or content
- **Top-left**: Less common, use when other positions interfere with content
