## Overview

The KeyboardKey component displays keyboard keys in a visually appealing and consistent manner. It's perfect for documentation, tutorials, keyboard shortcuts display, and any interface where you need to represent keyboard input. The component supports multiple variants, sizes, states, and can be rendered as different HTML elements.

## Accessibility

Our KeyboardKey component follows accessibility best practices:

- **Semantic HTML**: Uses `<kbd>` elements by default for semantic representation of keyboard input
- **Keyboard Navigation**: When clickable, provides full keyboard support with Enter and Space key activation
- **Screen Reader Support**: Proper ARIA attributes including `aria-disabled` for disabled states
- **Focus Management**: Clear focus indicators and logical tab order for interactive keys
- **Flexible Elements**: Supports different HTML elements through the `as` prop for various semantic contexts

## Best Practices

### Do's ✅

- Use semantic `<kbd>` elements for representing actual keyboard input
- Group related keys logically (e.g., modifier keys together)
- Use consistent sizing within the same context
- Provide clear visual hierarchy with appropriate variants
- Use the pressed state to show active shortcuts or current input
- Combine keys with separators (+ symbols) for complex shortcuts

### Don'ts ❌

- Don't use keyboard keys for general buttons or actions unrelated to keyboard input
- Avoid mixing too many different variants in the same context
- Don't make keys too small for comfortable reading (minimum recommended: sm size)
- Avoid using only color to convey key states - use shape and contrast as well
- Don't overcrowd interfaces with too many keyboard shortcuts at once

### Common Patterns

```jsx
// Keyboard shortcut documentation
<div style={{ display: 'flex', alignItems: 'center', gap: '4px' }}>
  <KeyboardKey size="sm">Ctrl</KeyboardKey>
  <span>+</span>
  <KeyboardKey size="sm">Shift</KeyboardKey>
  <span>+</span>
  <KeyboardKey size="sm">P</KeyboardKey>
  <span style={{ marginLeft: '8px', color: '#666' }}>Open Command Palette</span>
</div>

// Key mapping table
<table>
  <tr>
    <td><KeyboardKey size="sm">W</KeyboardKey></td>
    <td>Move forward</td>
  </tr>
  <tr>
    <td><KeyboardKey size="sm">S</KeyboardKey></td>
    <td>Move backward</td>
  </tr>
</table>

// Tutorial highlighting
<p>
  Press <KeyboardKey pressed>Enter</KeyboardKey> to confirm your selection.
</p>
```

### Keyboard Shortcut Guidelines

- **Platform Conventions**: Use appropriate modifier keys for each platform (Cmd on Mac, Ctrl on Windows/Linux)
- **Visual Hierarchy**: Make primary shortcuts more prominent than secondary ones
- **Grouping**: Group related shortcuts together and separate different categories
- **Context**: Show shortcuts only when they're available and relevant to the current context
