## Overview

The Rating component allows users to view and interact with star-based rating systems. It supports full and half-star precision, multiple sizes and variants, and provides comprehensive accessibility features. Perfect for product reviews, user feedback, and any scenario requiring star ratings.

<Canvas of={RatingStories.Default} />

## Basic Usage

The simplest way to use the Rating component is to display a static rating value.

```jsx
<Rating value={4} />
<Rating value={3.5} precision={0.5} />
```

<Unstyled>
    {(() => {
        const [rating1, setRating1] = useState(4);

    })()}

</Unstyled>

## Accessibility

Our Rating component follows accessibility best practices:

- **Semantic HTML**: Uses proper ARIA attributes and roles
- **Keyboard Navigation**: Full keyboard support for interactive ratings
- **Screen Reader Support**: Clear labels and value announcements
- **Focus Management**: Visible focus indicators and logical tab order
- **ARIA Labels**: Proper labeling for assistive technologies
- **Live Regions**: Dynamic value updates announced to screen readers

### Keyboard Navigation

- **Tab**: Move focus to the rating component
- **Arrow Keys**: Navigate between stars (when interactive)
- **Enter/Space**: Select the current star
- **Escape**: Clear focus

## Best Practices

### Do's ✅

- Use clear labels for accessibility
- Provide appropriate maximum values (typically 5 or 10)
- Show rating values when context is unclear
- Use readonly state for display-only ratings
- Consider half-star precision for detailed feedback
- Test with keyboard navigation

### Don'ts ❌

- Don't use ratings for binary choices (use checkboxes instead)
- Avoid too many stars (keep max reasonable)
- Don't make ratings too small for touch interaction
- Avoid using disabled state for validation feedback
- Don't rely on color alone to convey rating state

### Rating Scale Guidelines

- **1-5 stars**: Most common for general feedback
- **1-10 stars**: Better for detailed assessments
- **Half-stars**: Useful for more precise feedback
- **Custom scales**: Only when standard scales don't fit

### Form Integration

```jsx
function ReviewForm() {
    const [rating, setRating] = useState(0);
    const [comment, setComment] = useState("");

    return (
        <form onSubmit={handleSubmit}>
            <label>
                Overall Rating:
                <Rating
                    value={rating}
                    onChange={setRating}
                    label="Overall product rating"
                    required
                />
            </label>

            <textarea
                value={comment}
                onChange={(e) => setComment(e.target.value)}
                placeholder="Tell us about your experience..."
            />

            <button type="submit" disabled={rating === 0}>
                Submit Review
            </button>
        </form>
    );
}
```
