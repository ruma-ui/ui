## Accessibility

This component follows accessibility best practices:

- Semantic textarea element with proper labeling via `label` + `htmlFor`
- `aria-invalid` and `aria-describedby` for errors and helper text
- Clear focus outline and sufficient contrast
- Keyboard-friendly and screen-reader compatible

## Best Practices

### Do's ✅

- Use a clear label for every Textarea
- Provide helper text when necessary
- Set appropriate `rows` for expected content length
- Consider `resize` behavior based on use case
- Validate on blur or submit; keep error messages concise

### Don'ts ❌

- Don't rely solely on placeholder as a label
- Avoid long, paragraph-like helper text
- Don't show errors before the user has interacted
- Don't set `rows` too high for short content
