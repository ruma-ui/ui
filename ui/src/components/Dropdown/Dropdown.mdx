## Overview

The Dropdown component is a compound component system that provides a flexible dropdown menu with built-in accessibility, keyboard navigation, and consistent styling that matches the design system. It consists of several sub-components that work together to create dropdown menus.

<Canvas of={DropdownStories.Primary} />

## Basic Usage

The Dropdown component uses a compound pattern with multiple sub-components. The `DropdownMenu` provides context, `DropdownMenuTrigger` opens the menu, and `DropdownMenuContent` contains the menu items.

```tsx
<DropdownMenu>
  <DropdownMenuTrigger asChild>
    <Button variant='outline' endIcon={<FaChevronDown />}>
      Open Menu
    </Button>
  </DropdownMenuTrigger>
  <DropdownMenuContent>
    <DropdownMenuLabel>My Account</DropdownMenuLabel>
    <DropdownMenuSeparator />
    <DropdownMenuGroup>
      <DropdownMenuItem>
        <FaUser className='mr-2 h-4 w-4' />
        <span>Profile</span>
      </DropdownMenuItem>
      <DropdownMenuItem>
        <FaCog className='mr-2 h-4 w-4' />
        <span>Settings</span>
      </DropdownMenuItem>
      <DropdownMenuItem>
        <FaSignOutAlt className='mr-2 h-4 w-4' />
        <span>Sign Out</span>
      </DropdownMenuItem>
    </DropdownMenuGroup>
  </DropdownMenuContent>
</DropdownMenu>
```

## Component API

<ArgTypes of={DropdownStories} />

### DropdownMenu

The root component that provides context for the dropdown menu.

```tsx
<DropdownMenu open={open} onOpenChange={setOpen}>
  {/* children */}
</DropdownMenu>
```

**Props:**

- `children`: ReactNode - The dropdown menu content
- `open?`: boolean - Controlled open state
- `defaultOpen?`: boolean - Default open state
- `onOpenChange?`: (open: boolean) => void - Callback when open state changes

### DropdownMenuTrigger

The trigger element that opens/closes the dropdown menu.

```tsx
<DropdownMenuTrigger asChild>
  <Button>Open Menu</Button>
</DropdownMenuTrigger>
```

**Props:**

- `children`: ReactNode - The trigger element content
- `asChild?`: boolean - Whether to merge props onto the child element

### DropdownMenuContent

The content container for the dropdown menu.

```tsx
<DropdownMenuContent align='bottom-start' className='w-56'>
  {/* menu items */}
</DropdownMenuContent>
```

**Props:**

- `children`: ReactNode - The menu content
- `align?`: "bottom-start" | "bottom-end" | "top-start" | "top-end" - Content alignment
- `className?`: string - Additional CSS classes

### DropdownMenuItem

An interactive menu item.

```tsx
<DropdownMenuItem onSelect={handleSelect}>
  <FaUser className='mr-2 h-4 w-4' />
  <span>Menu Item</span>
</DropdownMenuItem>
```

**Props:**

- `children`: ReactNode - The item content
- `disabled?`: boolean - Whether the item is disabled
- `onSelect?`: () => void - Callback when item is selected
- All standard button HTML attributes

### DropdownMenuLabel

A non-interactive label for grouping menu items.

```tsx
<DropdownMenuLabel>My Account</DropdownMenuLabel>
```

**Props:**

- `children`: ReactNode - The label text

### DropdownMenuSeparator

A visual separator between menu sections.

```tsx
<DropdownMenuSeparator />
```

**Props:**

- `className?`: string - Additional CSS classes

### DropdownMenuGroup

A grouping container for menu items.

```tsx
<DropdownMenuGroup>
  <DropdownMenuItem>Item 1</DropdownMenuItem>
  <DropdownMenuItem>Item 2</DropdownMenuItem>
</DropdownMenuGroup>
```

**Props:**

- `children`: ReactNode - The grouped content

## Accessibility

The Dropdown component follows WAI-ARIA guidelines and includes comprehensive accessibility features:

- **Keyboard Navigation**: Full keyboard support with Escape key to close
- **Screen Reader Support**: Proper ARIA attributes and role definitions
- **Focus Management**: Clear focus indicators and logical focus flow
- **Click Outside**: Automatically closes when clicking outside the dropdown

## Best Practices

### When to Use

- **Action Menus**: For user account menus, settings menus, or action lists
- **Navigation Menus**: For dropdown navigation or context menus
- **Selection Menus**: When you need to present multiple options in a compact space
- **Contextual Actions**: For right-click menus or contextual dropdowns

### When Not to Use

- **Simple Selection**: Consider the Select component for choosing from a list of options with a single value
- **Simple Actions**: Use buttons for single actions
- **Large Content**: Consider modals or side panels for very large content
- **Complex Forms**: Use form components for structured data input

### Guidelines

1. **Clear Triggers**: Use descriptive trigger text or icons that clearly indicate the dropdown's purpose
2. **Logical Content**: Organize dropdown content in a logical, scannable way
3. **Appropriate Size**: Don't make dropdowns too wide or tall - keep content focused
4. **Consistent Alignment**: Choose alignment that prevents the dropdown from being cut off by viewport edges
5. **Performance**: For dynamic content, consider lazy loading or virtualization for large lists
