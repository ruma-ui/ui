## Overview

The Form component provides a structured way to create forms with consistent styling, validation, and user experience. It includes FormField for individual inputs and FormSection for grouping related fields. The Form component handles form submission, basic validation, and provides loading and error states.

## FormField Component

FormField wraps individual form inputs with labels, descriptions, and error messages. It provides consistent spacing and styling.

```jsx
<FormField
  label="Email Address"
  description="We'll use this to send you updates"
  required
  error={hasError}
  errorMessage="Please enter a valid email"
>
  <TextInput type="email" placeholder="your@email.com" />
</FormField>
```

    </FormField>
  </div>
</Unstyled>

## FormSection Component

FormSection groups related form fields with an optional title and description. Use the `bordered` prop to visually separate sections.

```jsx
<FormSection title="Personal Information" description="Tell us about yourself" bordered>
  <FormField label="First Name" required>
    <TextInput placeholder="Enter your first name" />
  </FormField>
  <FormField label="Last Name" required>
    <TextInput placeholder="Enter your last name" />
  </FormField>
</FormSection>
```

### Form `onSubmit` and `onError`

The `onSubmit` callback is fired when the form is submitted successfully. The `onError` callback is fired when validation fails.

```jsx
<Form
  onSubmit={event => {
    console.log("Form submitted:", event);
  }}
  onError={errors => {
    console.log("Validation errors:", errors);
  }}
>
  ...
</Form>
```

### FormField `label`

The `label` prop displays text above the form field.

```jsx
<FormField label="Email Address">
  <TextInput type="email" />
</FormField>
```

### FormField `description`

The `description` prop displays helper text below the form field.

```jsx
<FormField label="Password" description="Must be at least 8 characters long">
  <TextInput type="password" />
</FormField>
```

### FormField `error`

The `error` prop shows the field in an error state with red styling.

```jsx
<FormField label="Email" error errorMessage="Please enter a valid email address">
  <TextInput type="email" />
</FormField>
```

### FormField `required`

The `required` prop adds a red asterisk to the label and enables validation.

```jsx
<FormField label="Name" required>
  <TextInput />
</FormField>
```

### FormSection `title`

The `title` prop displays a heading for the section.

```jsx
<FormSection title="Personal Information">...</FormSection>
```

### FormSection `bordered`

The `bordered` prop adds a border, background, and shadow to the section.

```jsx
<FormSection title="Section" bordered>
  ...
</FormSection>
```

## Accessibility

Our Form components follow accessibility best practices:

- **Semantic HTML**: Uses proper `<form>`, `<label>`, and `<fieldset>` elements
- **ARIA Attributes**: Proper `aria-describedby`, `aria-invalid`, and `aria-required` attributes
- **Keyboard Navigation**: Full keyboard support with logical tab order
- **Screen Reader Support**: Clear labeling and error announcements
- **Focus Management**: Visible focus indicators and proper focus flow
- **Error Identification**: Clear error messages associated with form fields

## Best Practices

### Do's ✅

- Use FormField for all form inputs to ensure consistent labeling and spacing
- Group related fields with FormSection for better organization
- Provide clear, descriptive labels for all form fields
- Include helpful descriptions when field purpose isn't obvious
- Use the `required` prop for mandatory fields
- Show loading states during form submission
- Provide clear error messages when validation fails
- Use appropriate input types (email, tel, etc.) and components (DatePicker for dates)

### Don'ts ❌

- Don't create forms without proper labels
- Avoid very long forms - break them into steps if needed
- Don't rely on placeholder text as the only label
- Avoid generic error messages like "Invalid input"
- Don't disable forms without clear indication of why
- Avoid mixing different sizes within the same form
- Don't use FormField for non-form content

### Form Layout Patterns

```jsx
// Simple contact form
<Form title="Contact Us">
  <FormField label="Name" required>
    <TextInput />
  </FormField>
  <FormField label="Email" required>
    <TextInput type="email" />
  </FormField>
  <FormField label="Message" required>
    <Textarea />
  </FormField>
</Form>

// Complex form with sections
<Form title="User Registration">
  <FormSection title="Account" bordered>
    <FormField label="Email" required>
      <TextInput type="email" />
    </FormField>
    <FormField label="Password" required>
      <TextInput type="password" />
    </FormField>
  </FormSection>
  <FormSection title="Profile" bordered>
    <FormField label="First Name" required>
      <TextInput />
    </FormField>
    <FormField label="Last Name" required>
      <TextInput />
    </FormField>
    <FormField label="Date of Birth">
      <DatePicker placeholder="Select your date of birth" />
    </FormField>
  </FormSection>
</Form>
```
