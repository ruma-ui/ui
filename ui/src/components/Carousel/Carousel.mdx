## Overview

The Carousel component provides a modern, accessible way to display multiple items in a sliding interface. It supports drag and swipe gestures, autoplay functionality, and various navigation options. Built with performance and accessibility in mind, it integrates seamlessly with your design system.

<Canvas of={CarouselStories.Default} />

## Basic Usage

The carousel requires an array of React elements as items. Each item will be displayed as a slide.

```jsx
const items = [<div>Slide 1</div>, <div>Slide 2</div>, <div>Slide 3</div>];

function MyComponent() {
  return <Carousel items={items} />;
}
```

<Canvas of={CarouselStories.Default} />

## Drag and Swipe

The carousel supports drag and swipe gestures on both desktop and mobile devices. Users can drag horizontally to navigate between slides.

<Canvas of={CarouselStories.Default} />

**Drag Features:**

- Smooth drag animations with visual feedback
- Configurable drag threshold (15% of container width)
- Disabled during transitions to prevent conflicts
- Touch and mouse support

## Autoplay

Enable automatic slide progression with customizable intervals. Autoplay can be paused on hover for better user experience.

<Canvas of={CarouselStories.WithAutoplay} />

```jsx
<Carousel items={items} autoplay={true} autoplayInterval={3000} pauseOnHover={true} />
```

## Navigation Options

### Navigation Arrows

Arrow buttons appear on the left and right sides for manual navigation. They are automatically hidden when not needed (single slide or at boundaries in finite mode).

### Dot Indicators

Clickable dots at the bottom show the current position and allow direct navigation to any slide.

## Infinite vs Finite

Choose between infinite loop navigation or finite boundaries.

### Infinite (Default)

<Canvas of={CarouselStories.Default} />

Allows continuous navigation in both directions.

### Finite

<Canvas of={CarouselStories.NonInfinite} />

Stops at the first and last slides, disabling navigation arrows accordingly.

## Controlled vs Uncontrolled

The carousel can be used in controlled or uncontrolled modes.

### Uncontrolled (Default)

```jsx
<Carousel items={items} defaultActiveIndex={0} />
```

### Controlled

```jsx
const [activeIndex, setActiveIndex] = useState(0);

<Carousel items={items} activeIndex={activeIndex} onChange={setActiveIndex} />;
```

<Canvas of={CarouselStories.Controlled} />

### Carousel `activeIndex` and `defaultActiveIndex`

Control the currently displayed slide. Use `activeIndex` for controlled mode or `defaultActiveIndex` for uncontrolled mode.

```jsx
// Uncontrolled
<Carousel items={items} defaultActiveIndex={1} />;

// Controlled
const [index, setIndex] = useState(0);
<Carousel items={items} activeIndex={index} onChange={setIndex} />;
```

## Accessibility

The Carousel component follows WCAG guidelines and accessibility best practices:

- **Keyboard Navigation**: Full support for arrow keys, Home, and End keys
- **Screen Reader Support**: Proper ARIA labels and live regions
- **Focus Management**: Logical tab order and visible focus indicators
- **Touch Support**: Optimized for mobile devices with proper touch handling
- **Reduced Motion**: Respects user's motion preferences

**Keyboard Controls:**

- `←` `→` - Navigate between slides
- `Home` - Go to first slide
- `End` - Go to last slide

## Best Practices

### Do's ✅

- Use high-quality images or content for slides
- Keep slide count reasonable (3-10 slides typically)
- Ensure sufficient contrast for navigation elements
- Test on various screen sizes and devices
- Provide meaningful alt text for images
- Use autoplay sparingly and always with pause-on-hover

### Don'ts ❌

- Don't overload slides with too much content
- Avoid autoplay without user control options
- Don't hide navigation controls unnecessarily
- Avoid very fast animation durations (< 150ms)
- Don't use the carousel for critical content navigation

### Content Guidelines

- **Images**: Use optimized images with proper aspect ratios
- **Text**: Keep text concise and scannable
- **Interactive Elements**: Ensure buttons and links are accessible
- **Loading States**: Consider lazy loading for performance

## Performance

The Carousel component is optimized for performance:

- **Efficient Rendering**: Only renders visible content
- **Smooth Animations**: Uses CSS transforms for 60fps animations
- **Memory Management**: Proper cleanup of timers and event listeners
- **Bundle Size**: Minimal dependencies, tree-shakable

**Performance Tips:**

- Use lazy loading for slide content
- Optimize images and media
- Limit the number of slides when possible
- Consider virtual scrolling for large datasets
