## Overview

A segmented, accessible date input with optional calendar popover. Users can type using day/month/year segments or pick a date visually. Includes validation for ranges and proper keyboard support.

## Accessibility

- **Keyboard navigation**: Arrow keys to move between segments, `/` to advance, Escape to close calendar
- **Screen readers**: Proper labeling via `label` and descriptions via `description`/`error`
- **Focus outlines**: Visible focus for inputs and calendar cells
- **ARIA**: Calendar grid exposes roles and selection state

## Best Practices

- **Use ranges**: Always provide `minDate`/`maxDate` when business rules require
- **Guide users**: Include `label` and `description` for expected format
- **Typing + picking**: Keep `withCalendar` enabled for faster input when possible
- **Validation**: Show helpful error messages and don’t block typing mid-entry
