## Overview

Skeleton components provide visual placeholders that mimic the layout of content while it's loading. They improve perceived performance and user experience by giving users a preview of the content structure before the actual data loads. Our Skeleton component is designed to be flexible, customizable, and consistent with our design system.

### Rectangle Variant

### Skeleton `variant`

The `variant` prop determines the shape and appearance of the skeleton. Choose the variant that best matches your content type.

```jsx

<Skeleton variant="text" width={300} lines={2} />
```

### Skeleton `width` and `height`

Control the exact dimensions of your skeleton using the `width` and `height` props. These accept numbers (pixels) or strings (percentages, etc.).

```jsx
// Pixel dimensions
<Skeleton width={300} height={200} />

// Percentage dimensions
<Skeleton width="100%" height="200px" />

// Mixed dimensions
<Skeleton width="50%" height={100} />
```

**Animation Guide:**

- **Shimmer**: Creates a sweeping light effect that moves across the skeleton - provides clear visual feedback (default)
- **Wave**: Similar to shimmer but with a more pronounced wave-like movement
- **Fade**: Smooth opacity transitions for a subtle loading effect
- **Pulse**: Subtle opacity changes - good for less intrusive loading states
- **None**: No animation - useful when you want static placeholders

### Skeleton `lines`

For text variants, control how many lines of skeleton text to display. The last line is automatically shorter to mimic real text content.

```jsx
<Skeleton variant="text" lines={1} width={300} />
<Skeleton variant="text" lines={3} width={300} />
<Skeleton variant="text" lines={5} width={300} />
```

### Skeleton `show`

Control whether the skeleton is visible or not. Useful for conditional rendering based on loading states.

```jsx
const [isLoading, setIsLoading] = useState(true);

// Show skeleton while loading
{
  isLoading && <Skeleton width={200} height={100} />;
}

// Hide skeleton when loading is complete
{
  !isLoading && <ActualContent />;
}
```

### Skeleton `className`

Add custom styling while preserving the skeleton's built-in styles. Useful for custom colors, borders, or spacing.

```jsx
<Skeleton className="bg-blue-100" width={200} height={40} />
<Skeleton className="rounded-full" variant="rectangle" width={200} height={40} />
<Skeleton className="border border-gray-300" width={200} height={40} />
```

## Accessibility

Our Skeleton component follows accessibility best practices:

- **Screen Reader Support**: Uses `aria-hidden="true"` to prevent screen readers from announcing skeleton content
- **Semantic HTML**: Uses appropriate `<div>` elements with proper ARIA attributes
- **Color Contrast**: Ensures sufficient contrast between skeleton and background colors
- **Animation Preferences**: Respects user's `prefers-reduced-motion` settings
- **Loading Context**: Can be combined with `aria-busy` on parent containers

## Best Practices

### Do's ✅

- Use skeletons that closely match your actual content layout
- Keep skeleton dimensions consistent with loaded content
- Use shimmer animation for better perceived performance
- Combine multiple skeleton variants for complex layouts
- Test skeleton loading states on slow connections
- Use appropriate contrast ratios for accessibility

### Don'ts ❌

- Don't use skeletons for content that loads very quickly (< 100ms)
- Avoid overly complex skeleton layouts that take time to build
- Don't make skeletons too different from actual content dimensions
- Avoid using skeletons for error states
- Don't rely solely on skeletons without proper loading indicators

### Skeleton Layout Patterns

```jsx
// Card layout
<div className="card">
  <Skeleton variant="rectangle" width="100%" height={200} />
  <Skeleton variant="text" width="100%" lines={2} className="mt-4" />
  <Skeleton variant="text" width="60%" lines={1} className="mt-2" />
</div>

// List item layout
<div className="flex items-center gap-4">
  <Skeleton variant="circle" width={48} height={48} />
  <div className="flex-1">
    <Skeleton variant="text" width="100%" lines={1} />
    <Skeleton variant="text" width="70%" lines={1} size="sm" className="mt-1" />
  </div>
</div>

// Table row layout
<div className="grid grid-cols-4 gap-4">
  <Skeleton variant="text" width="100%" lines={1} />
  <Skeleton variant="text" width="100%" lines={1} />
  <Skeleton variant="text" width="100%" lines={1} />
  <Skeleton variant="text" width="100%" lines={1} />
</div>
```

### Performance Considerations

```jsx
// Efficient skeleton rendering
const LoadingCard = () => (
  <div className='card'>
    <Skeleton variant='rectangle' width='100%' height={200} />
    <div className='p-4'>
      <Skeleton variant='text' width='100%' lines={2} />
      <Skeleton variant='text' width='60%' lines={1} className='mt-2' />
    </div>
  </div>
);

// Conditional rendering based on loading state
const Content = ({ isLoading, data }) => {
  if (isLoading) {
    return <LoadingCard />;
  }
  return <ActualCard data={data} />;
};
```
