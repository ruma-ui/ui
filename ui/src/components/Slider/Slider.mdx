## Overview

Sliders allow users to select a value from a continuous or discrete range by moving a thumb along a track. They provide an intuitive way to adjust settings like volume, brightness, or any numeric value within a defined range. Our Slider component is designed to be accessible, customizable, and consistent with our design system.

## Controlled vs Uncontrolled

### Uncontrolled (Default)

Uncontrolled sliders manage their own state internally.

```jsx
<Slider defaultValue={50} onChange={value => console.log(value)} />
```

### Controlled

Controlled sliders accept a `value` prop and require an `onChange` handler.

### Slider `value` and `defaultValue`

Control slider state for different usage patterns.

```jsx
// Uncontrolled - manages its own state
<Slider defaultValue={50} />;

// Controlled - parent manages state
const [value, setValue] = useState(50);
<Slider value={value} onChange={setValue} />;
```

## Accessibility

Our Slider component follows accessibility best practices:

- **Semantic HTML**: Uses proper ARIA attributes for screen readers
- **Keyboard Navigation**: Full support for arrow keys, Home, End, Page Up/Down
- **Screen Reader Support**: Proper labeling with `aria-valuemin`, `aria-valuemax`, `aria-valuenow`
- **Focus Management**: Clear focus indicators and logical tab order
- **Touch Support**: Optimized for touch interactions on mobile devices
- **High Contrast**: Sufficient color contrast in all variants

### Keyboard Controls

- **Arrow Left/Right**: Decrease/increase by step value
- **Arrow Up/Down**: Same as left/right for consistency
- **Home**: Jump to minimum value
- **End**: Jump to maximum value
- **Page Up/Down**: Large increments (10% of range)

## Best Practices

### Do's ✅

- Use sliders for continuous or discrete numeric values
- Provide clear labels that explain what the slider controls
- Show values when precision matters to the user
- Use appropriate min/max values for your use case
- Consider step values for discrete selections (ratings, levels)
- Test with keyboard navigation for accessibility
- Use descriptions for complex or unfamiliar controls

### Don'ts ❌

- Don't use sliders for non-numeric values
- Avoid very large ranges without proper step values
- Don't hide important sliders behind feature flags
- Avoid using sliders for binary choices (use switches instead)
- Don't make sliders too small for touch interaction
- Avoid excessive decimal precision without good reason
