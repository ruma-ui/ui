## Overview

The RangeInput component provides a dual-thumb slider interface for selecting numeric ranges. It supports both controlled and uncontrolled usage patterns and integrates seamlessly with your design system.

<Canvas of={RangeInputStories.Default} />

## Basic Usage

The RangeInput can be used as a simple range selector with default settings.

```jsx
function MyComponent() {
  const [range, setRange] = useState([20, 80]);

  return <RangeInput value={range} onChange={setRange} label='Select a range' />;
}
```

## Component API

<ArgTypes of={RangeInput} />

### RangeInput `value`

The `value` prop controls the current range values when using the RangeInput as a controlled component. It should be a tuple of two numbers `[min, max]`.

```jsx
<RangeInput value={[20, 80]} onChange={setRange} />
```

### RangeInput `defaultValue`

The `defaultValue` prop sets the initial range values for uncontrolled components.

```jsx
<RangeInput defaultValue={[10, 90]} />
```

### RangeInput `min` and `max`

The `min` and `max` props define the range boundaries for the slider.

```jsx
<RangeInput min={0} max={100} defaultValue={[25, 75]} />
```

### RangeInput `step`

The `step` prop controls the increment value for range adjustments.

```jsx
<RangeInput step={5} defaultValue={[20, 80]} />;
{
  /* Increments by 5 */
}
<RangeInput step={0.1} defaultValue={[1.5, 2.5]} />;
{
  /* Increments by 0.1 */
}
```

### RangeInput `variant`

The `variant` prop determines the visual style of the range input.

```jsx
<RangeInput variant='primary' />;
{
  /* Blue styling */
}
<RangeInput variant='secondary' />;
{
  /* Gray styling */
}
```

### RangeInput `size`

The `size` prop controls the overall dimensions of the range input.

```jsx
<RangeInput size='sm' />;
{
  /* Small size */
}
<RangeInput size='md' />;
{
  /* Medium size (default) */
}
<RangeInput size='lg' />;
{
  /* Large size */
}
```

### RangeInput `showValue`

The `showValue` prop displays the current range values next to the label.

```jsx
<RangeInput showValue={true} defaultValue={[30, 70]} />
```

### RangeInput `valueFormatter`

The `valueFormatter` prop allows custom formatting of the displayed values.

```jsx
<RangeInput valueFormatter={value => `$${value}`} defaultValue={[50, 200]} />
```

### RangeInput `label`

The `label` prop adds a label above the range input for better accessibility and user experience.

```jsx
<RangeInput label='Price Range' />
```

### RangeInput `description`

The `description` prop adds helper text below the range input.

```jsx
<RangeInput label='Volume' description='Adjust the volume level' />
```

### RangeInput `error`

The `error` prop displays the range input in an error state with red styling.

```jsx
<RangeInput error={true} errorMessage='Please select a valid range' />
```

### RangeInput `onChange`

The `onChange` callback is called whenever the selected range changes.

```jsx
<RangeInput
  onChange={range => {
    console.log("Selected range:", range);
    // range is [min, max]
  }}
/>
```

### RangeInput `onChangeEnd`

The `onChangeEnd` callback is called when the user finishes adjusting the range (on mouse/touch release or key press).

```jsx
<RangeInput
  onChangeEnd={range => {
    console.log("Range adjustment complete:", range);
    // Perform final validation or API calls
  }}
/>
```

## Accessibility

Our RangeInput component follows accessibility best practices:

- **Keyboard Navigation**: Full support for Tab navigation between thumbs and arrow key adjustments
- **Screen Reader Support**: Proper ARIA labels, values, and descriptions for both thumbs
- **Focus Management**: Clear focus indicators and logical tab order
- **Semantic HTML**: Uses appropriate HTML elements with correct attributes
- **Dual Thumb Support**: Each thumb is independently accessible with proper ARIA attributes

## Best Practices

### Do's ✅

- Use clear, descriptive labels for range inputs
- Provide appropriate min/max values for your use case
- Consider using `valueFormatter` for user-friendly value display
- Use `showValue` when users need to see exact values
- Provide helpful descriptions for complex ranges
- Test keyboard navigation thoroughly

### Don'ts ❌

- Don't use range inputs for single value selection (use regular sliders instead)
- Avoid very small ranges that make precise selection difficult
- Don't hide values when precision is important
- Avoid using ranges for non-numeric data
- Don't make ranges too wide without considering step sizes

### Range Input Combinations

```jsx
// Filter controls
<div className="space-y-4">
  <RangeInput
    label="Price Range"
    min={0}
    max={1000}
    defaultValue={[100, 500]}
    showValue={true}
    valueFormatter={(value) => `$${value}`}
  />
  <RangeInput
    label="Rating"
    min={1}
    max={5}
    step={0.5}
    defaultValue={[3, 5]}
    showValue={true}
  />
</div>

// Audio controls
<RangeInput
  label="Frequency Range"
  min={20}
  max={20000}
  defaultValue={[100, 10000]}
  valueFormatter={(value) => `${value}Hz`}
/>
```
