## Accessibility

Our FileUpload component follows accessibility best practices:

- **Semantic HTML**: Uses proper `<input type="file">` elements with appropriate ARIA attributes
- **Keyboard Navigation**: Full support for keyboard navigation and activation
- **Screen Reader Support**: Proper labeling with `aria-label` and `aria-describedby`
- **Focus Management**: Clear focus indicators and logical tab order
- **Error Communication**: Validation errors are communicated to assistive technologies
- **Drag and Drop**: Proper ARIA live regions for drag and drop feedback

## Best Practices

### Do's ✅

- Always provide clear placeholder text that explains what types of files are accepted
- Use appropriate file type restrictions with the `accept` prop
- Set reasonable file size limits based on your application's needs
- Provide feedback for successful uploads and validation errors
- Use the `multiple` prop appropriately - only when users need to upload multiple files
- Test with real files to ensure validation works as expected
- Consider mobile users when designing upload interfaces

### Don'ts ❌

- Don't use file upload for simple text input - use appropriate form controls
- Avoid overly restrictive file type limits that frustrate users
- Don't hide file size limits - always communicate them clearly
- Avoid using file upload for large files without progress indicators
- Don't disable drag and drop without a good reason
- Avoid generic placeholder text like "Upload file"

### File Upload Patterns

```jsx
// Document upload with validation
<FileUpload
    accept=".pdf,.doc,.docx"
    maxSize={10 * 1024 * 1024} // 10MB
    placeholder="Upload your documents"
    buttonText="Select Documents"
/>

// Image upload with preview
<FileUpload
    accept="image/*"
    maxSize={5 * 1024 * 1024} // 5MB
    placeholder="Upload images"
    buttonText="Choose Images"
/>

// Multiple file upload
<FileUpload
    multiple
    maxFiles={5}
    accept="image/*,.pdf"
    placeholder="Upload up to 5 files"
    buttonText="Select Files"
/>
```
