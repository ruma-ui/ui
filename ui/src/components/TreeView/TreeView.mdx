## Overview

TreeView is a hierarchical component that displays nested data in a tree-like structure. It supports selection, expansion/collapse, and keyboard navigation, making it ideal for file explorers, navigation menus, and data hierarchies.

<Canvas of={TreeViewStories.Basic} />

## Basic Usage

The TreeView component consists of several sub-components that work together:

- `TreeView`: The root container
- `TreeItem`: Individual tree nodes
- `TreeItemContent`: The clickable content area
- `TreeItemTrigger`: Expandable trigger for parent nodes
- `TreeItemChildren`: Container for child nodes

<Canvas of={TreeViewStories.Basic} />

## Selection Modes

### Single Selection

By default, TreeView allows only one item to be selected at a time. Clicking on an item will deselect any previously selected item.

<Canvas of={TreeViewStories.SingleSelection} />

### Multiple Selection

Set `multiple={true}` to allow multiple items to be selected simultaneously. Use Ctrl+Click (or Cmd+Click on Mac) to select multiple items.

<Canvas of={TreeViewStories.MultipleSelection} />

## Expansion Modes

### Multiple Expansion

By default, multiple tree branches can be expanded at once, allowing users to view multiple sections of the hierarchy simultaneously.

<Canvas of={TreeViewStories.Basic} />

### Single Expansion

Set `multipleExpanded={false}` to allow only one branch to be expanded at a time. Expanding a new branch will automatically collapse any previously expanded branches.

<Canvas of={TreeViewStories.SingleExpansion} />

## Pre-selected State

You can initialize the TreeView with pre-selected and pre-expanded items using the `defaultSelected` and `defaultExpanded` props.

<Canvas of={TreeViewStories.PreSelected} />

## Simple List

For simple flat lists without hierarchy, you can omit the `TreeItemTrigger` and `TreeItemChildren` components.

<Canvas of={TreeViewStories.SimpleList} />

## Nested Structure

TreeView supports unlimited nesting levels, making it suitable for complex hierarchical data structures.

<Canvas of={TreeViewStories.Basic} />

## Indentation Guides

Indentation guides provide visual cues to help users understand the hierarchical structure of the tree. They appear as vertical lines connecting parent and child items.

### TreeView `defaultSelected`

An array of item values that should be selected when the component mounts.

```jsx
<TreeView defaultSelected={["item1", "item3"]}>
  <TreeItem value='item1'>Item 1</TreeItem>
  <TreeItem value='item2'>Item 2</TreeItem>
  <TreeItem value='item3'>Item 3</TreeItem>
</TreeView>
```

### TreeView `defaultExpanded`

An array of item values that should be expanded when the component mounts.

```jsx
<TreeView defaultExpanded={["folder1"]}>
  <TreeItem value='folder1'>
    <TreeItemContent>
      <TreeItemTrigger hasChildren={true}>📁 Folder 1</TreeItemTrigger>
    </TreeItemContent>
    <TreeItemChildren>
      <TreeItem value='file1'>📄 File 1</TreeItem>
    </TreeItemChildren>
  </TreeItem>
</TreeView>
```

### TreeView `onSelectionChange`

Callback function called when the selection changes. Receives an array of selected item values.

```jsx
const handleSelectionChange = selectedItems => {
  console.log("Selected items:", selectedItems);
};

<TreeView onSelectionChange={handleSelectionChange}>{/* Tree items */}</TreeView>;
```

### TreeView `onExpansionChange`

Callback function called when the expansion state changes. Receives an array of expanded item values.

```jsx
const handleExpansionChange = expandedItems => {
  console.log("Expanded items:", expandedItems);
};

<TreeView onExpansionChange={handleExpansionChange}>{/* Tree items */}</TreeView>;
```

### TreeItem `value`

A unique identifier for the tree item. This value is used for selection and expansion state management.

```jsx
<TreeItem value='unique-id'>Item Content</TreeItem>
```

### TreeItem `disabled`

Disables the tree item, preventing selection and expansion.

```jsx
<TreeItem value='disabled-item' disabled>
  Disabled Item
</TreeItem>
```

### TreeItemTrigger `hasChildren`

Controls whether the expansion icon is displayed. Set to `true` for items that have children, `false` for leaf nodes.

```jsx

```

## Accessibility

Our TreeView component follows accessibility best practices:

- **Semantic HTML**: Uses proper ARIA attributes for tree structure
- **Keyboard Navigation**: Full support for arrow keys, Enter, and Space
- **Screen Reader Support**: Proper labeling with `aria-expanded`, `aria-selected`, and `aria-disabled`
- **Focus Management**: Clear focus indicators and logical tab order
- **Role Attributes**: Uses `role="tree"` and `role="treeitem"` for screen readers

### Keyboard Navigation

- **Arrow Up/Down**: Navigate between sibling items
- **Arrow Left**: Collapse current item or move to parent
- **Arrow Right**: Expand current item or move to first child
- **Enter/Space**: Select current item
- **Home/End**: Navigate to first/last item in current level

## Best Practices

### Do's ✅

- Use clear, descriptive labels for tree items
- Provide appropriate icons to distinguish between files and folders
- Consider the depth of your hierarchy (avoid deeply nested structures when possible)
- Use consistent indentation and spacing
- Provide visual feedback for selected and expanded states
- Test with keyboard navigation

### Don'ts ❌

- Don't use TreeView for simple flat lists (use regular lists instead)
- Avoid very deep nesting (more than 5-6 levels)
- Don't mix different types of content without clear visual distinction
- Avoid using TreeView for large datasets (consider virtualization)
- Don't disable items without clear visual indication

### Performance Considerations

For large tree structures:

```jsx
// Use React.memo for tree items
const TreeItem = React.memo(({ value, children, ...props }) => {
  // Implementation
});

// Consider lazy loading for large hierarchies
const TreeItemChildren = ({ children, isExpanded }) => {
  return <div className={isExpanded ? "visible" : "hidden"}>{isExpanded ? children : null}</div>;
};
```

### Common Patterns

```jsx
// File explorer pattern
<TreeView multiple multipleExpanded>
  <TreeItem value="folder">
    <TreeItemContent>
      <TreeItemTrigger hasChildren={true}>
        <FaFolder className="text-blue-500" />
        <span>Documents</span>
      </TreeItemTrigger>
    </TreeItemContent>
    <TreeItemChildren>
      <TreeItem value="file">

          <span>document.pdf</span>
```
