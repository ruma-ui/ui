## Accessibility

The Badge component follows accessibility best practices and includes:

- **Semantic Colors**: Color variants that convey meaning beyond just visual appearance
- **Keyboard Navigation**: Full keyboard support for clickable and dismissible badges
- **Focus Management**: Clear focus indicators and proper focus handling
- **Screen Reader Support**: Appropriate ARIA labels for interactive elements
- **Color Contrast**: All variants meet WCAG color contrast requirements

## Best Practices

### When to Use

- **Status Indicators**: For showing system status, user status, or content state
- **Labels and Tags**: For categorization, filtering, or metadata display
- **Notifications**: For unread counts, alerts, or attention-getting indicators
- **Feature Flags**: To highlight new features, beta status, or special conditions

### When Not to Use

- **Primary Actions**: Use buttons for primary actions instead of clickable badges
- **Long Text**: Keep badge content concise; use other components for longer text
- **Complex Information**: Use cards or other components for detailed information
- **Navigation**: Don't use badges as primary navigation elements

### Guidelines

1. **Concise Content**: Keep badge text short and meaningful
2. **Consistent Usage**: Use the same variants for the same types of information
3. **Appropriate Colors**: Choose variants that match the semantic meaning
4. **Icon Clarity**: Use icons that clearly represent the badge's purpose
5. **Interaction Feedback**: Provide clear feedback for clickable and dismissible badges
6. **Performance**: Avoid excessive badge animations or complex interactions

### Content Guidelines

1. **Clear Language**: Use specific, actionable language that users understand
2. **Consistent Terminology**: Use the same terms for similar concepts across badges
3. **Appropriate Tone**: Match the badge tone to your application's voice
4. **Number Formatting**: Use appropriate formatting for counts (e.g., "99+" for large numbers)
5. **Status Accuracy**: Keep status badges accurate and up-to-date
