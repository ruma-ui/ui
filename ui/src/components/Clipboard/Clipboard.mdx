## Overview

The Clipboard component provides an easy way to copy text content to the user's clipboard with visual feedback. It handles the clipboard API and provides consistent styling that matches our design system with smooth transitions and proper focus states.

### Clipboard `value`

The `value` prop specifies the text content that will be copied to the clipboard when the button is clicked. This is a required prop.

```jsx
<Clipboard value="https://example.com" />
<Clipboard value="npm install @rumaui/ui" />
```

### Clipboard `tooltip`

The `tooltip` prop adds a tooltip that appears on hover, providing additional context about the clipboard action. When content is copied and `showFeedback` is enabled, the tooltip automatically changes to display the feedback text. Defaults to "Copy to clipboard".

```jsx
<Clipboard value="text" tooltip="Copy to clipboard" />  // Changes to "Copied!" when clicked
<Clipboard value="text" tooltip="Copy API key" />       // Changes to feedback text when clicked
```

### Clipboard `onCopy` and `onError`

The `onCopy` callback is fired when text is successfully copied to the clipboard. The `onError` callback is fired when the copy operation fails.

```jsx
<Clipboard
  value="text"
  onCopy={copiedValue => console.log("Copied:", copiedValue)}
  onError={error => console.error("Copy failed:", error)}
>
  Copy with callbacks
</Clipboard>
```

## Accessibility

Our Clipboard component follows accessibility best practices:

- **Semantic HTML**: Uses proper `<button>` elements with correct ARIA attributes
- **Keyboard Navigation**: Full support for Enter and Space key activation
- **Screen Reader Support**: Proper labeling with `aria-label` that updates based on state
- **Focus Management**: Clear focus indicators and logical tab order
- **State Communication**: Screen readers are informed when content is copied
- **Error Handling**: Failed copy operations are communicated to assistive technologies

## Best Practices

### Do's ✅

- Always provide meaningful `value` content to copy
- Use tooltips to provide context, especially for icon-only variants (they automatically change to show feedback when copied)
- Choose appropriate variants based on visual hierarchy (primary for prominent, secondary for subtle)
- Test clipboard functionality across different browsers
- Use appropriate feedback duration (2-3 seconds is usually ideal)
- Consider accessibility - ensure sufficient color contrast and hover states

### Don'ts ❌

- Don't use clipboard triggers for non-copy actions
- Avoid very long feedback durations that might confuse users
- Don't disable copy functionality without clear visual indication
- Avoid using clipboard for sensitive information without user consent
- Don't rely on clipboard functionality as the only way to access content
- Don't use icon-only variants without tooltips for clarity

### Usage Examples

```jsx
// Basic usage (icon-only with default tooltip that changes to "Copied!")
<Clipboard value="https://example.com" />

// With custom tooltip that changes to feedback text when copied
<Clipboard
    value="npm install @rumaui/ui"
    tooltip="Copy install command"
/>

// With text label
<Clipboard
    value="api-key-12345"
    iconOnly={false}
    tooltip="Copy API key"
>
    Copy Key
</Clipboard>

// With custom feedback
<Clipboard
    value="secret-token"
    feedbackText="🔑 Token copied!"
    feedbackDuration={3000}
    tooltip="Copy authentication token"
/>

// With animations
<Clipboard
    value="text"
    animation="scale"
    variant="primary"
/>

// In a code block
<div className="relative bg-gray-900 p-4 rounded">
    <pre><code>const code = "example";</code></pre>
    <Clipboard
        value='const code = "example";'
        className="absolute top-2 right-2"
        variant="secondary"
        tooltip="Copy code"
    />
</div>

// With callbacks
<Clipboard
    value="text"
    onCopy={(value) => console.log('Copied:', value)}
    onError={(error) => console.error('Copy failed:', error)}
/>
```
