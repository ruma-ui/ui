## Overview

Links are navigational elements that allow users to move between pages, sections, or external resources. Our Link component provides consistent styling, accessibility features, and flexible customization options.

<Canvas of={LinkStories.Primary} />

## Variants

### Primary Variant

The primary link is used for main navigation items and important actions. It uses the primary color to draw attention and indicate significance.

<Canvas of={LinkStories.Primary} />

### Secondary Variant

Secondary links are used for less prominent navigation items or when you need a more subtle appearance while maintaining good readability.

<Canvas of={LinkStories.Secondary} />

### Tertiary Variant

Tertiary links provide the most subtle appearance, perfect for metadata, footers, or when you need minimal visual weight.

<Canvas of={LinkStories.Tertiary} />

### Destructive Variant

Use destructive links for actions that lead to deletion, removal, or other potentially harmful operations. The red color provides a clear visual warning.

<Canvas of={LinkStories.Destructive} />

### None Variant

The none variant provides a completely unstyled link that can be customized with your own styles via the `className` prop.

### Link `variant`

The `variant` prop determines the visual style and hierarchy of the link. Choose the appropriate variant based on the link's importance and context.

```jsx
<Link href="/home" variant="primary">Primary Link</Link>
<Link href="/about" variant="secondary">Secondary Link</Link>
<Link href="/help" variant="tertiary">Tertiary Link</Link>
<Link href="/delete" variant="destructive">Delete Account</Link>
<Link href="/custom" variant="none">Unstyled Link</Link>
```

- **Scale**: Slightly enlarges on hover, shrinks on click - great for important navigation
- **Glow**: Adds a colored shadow glow - draws attention to special links
- **Lift**: Combines upward movement with shadow - modern, interactive feel
- **Press**: Only animates on click - minimal but responsive feedback

### Link `external`

Control whether the link opens in a new tab and includes proper security attributes.

```jsx
// Automatic detection (recommended)
<Link href="/internal">Internal Link</Link>
<Link href="https://external.com">External Link</Link>
<Link href="mailto:hello@example.com">Email Link</Link>

// Explicit control
<Link href="/page" external={true}>Force External</Link>
```

## Accessibility

Our Link component follows accessibility best practices:

- **Semantic HTML**: Uses proper `<a>` elements with correct attributes
- **Keyboard Navigation**: Full support for Enter and Space key activation
- **Screen Reader Support**: Proper `href` attributes and meaningful link text
- **Focus Management**: Clear focus indicators with customizable focus rings
- **External Link Safety**: Automatic `rel="noopener noreferrer"` for external links
- **Context Awareness**: Smart detection of link types (email, phone, external)

## Best Practices

### Do's ✅

- Use descriptive link text that makes sense out of context (avoid "click here")
- Provide visual indication for external links (using end icons)
- Use appropriate variants to establish clear hierarchy
- Include focus rings for keyboard navigation
- Use consistent styling patterns across your application
- Provide adequate spacing between links (minimum 8px)

### Don'ts ❌

- Don't use vague link text like "read more" or "click here"
- Avoid removing focus indicators without providing alternatives
- Don't use destructive variants for non-destructive actions
- Avoid making links too small (minimum 44px touch target)
- Don't rely solely on color to convey link meaning
- Avoid breaking link functionality with custom styles

### Link Text Guidelines

```jsx
// Good: Descriptive and specific
<Link href="/user-guide">User Guide</Link>
<Link href="/contact">Contact Support</Link>
<Link href="/download">Download Report</Link>

// Bad: Vague and unclear
<Link href="/guide">Click here</Link>
<Link href="/contact">More info</Link>
<Link href="/download">Read more</Link>
```

### Navigation Patterns

```jsx
// Main navigation
<nav>
  <Link href="/" variant="primary">Home</Link>
  <Link href="/products" variant="secondary">Products</Link>
  <Link href="/about" variant="secondary">About</Link>
  <Link href="/contact" variant="secondary">Contact</Link>
</nav>

// Footer links
<footer>
  <Link href="/privacy" variant="tertiary" size="sm">Privacy Policy</Link>
  <Link href="/terms" variant="tertiary" size="sm">Terms of Service</Link>
  <Link href="/help" variant="tertiary" size="sm">Help Center</Link>
</footer>
```
