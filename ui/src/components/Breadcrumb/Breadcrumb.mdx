## Overview

The Breadcrumb component provides hierarchical navigation that shows users their current location within an application or website. It offers full customization with support for icons, item collapsing, and comprehensive accessibility features. By default, the separator between items is "/". You can customize it via the `separator` prop.

## Accessibility

The Breadcrumb component follows WAI-ARIA guidelines and includes comprehensive accessibility features:

- **Semantic HTML**: Uses `<nav>` and `<ol>` elements for proper structure
- **ARIA Labels**: Includes `aria-label="Breadcrumb"` for screen readers
- **Current Page**: Uses `aria-current="page"` for the current location
- **Keyboard Navigation**: Full keyboard support for focusable items
- **Screen Reader Support**: Proper announcement of breadcrumb structure and current location

## Best Practices

### When to Use

- **Hierarchical Navigation**: When your site has a clear hierarchical structure
- **Deep Navigation**: For applications with multiple levels of navigation
- **User Orientation**: When users need to understand their current location
- **Quick Navigation**: To provide shortcuts back to higher-level pages

### When Not to Use

- **Shallow Sites**: For simple sites with only one or two levels
- **Linear Processes**: In step-by-step processes where users shouldn't go back
- **Mobile First**: Consider if breadcrumbs add value on small screens

### Guidelines

- **Clear Labels**: Use descriptive, concise labels that clearly identify each level
- **Logical Hierarchy**: Ensure breadcrumbs reflect the actual site structure
- **Current Page**: Make the current page visually distinct (usually not linked)
- **Consistent Placement**: Place breadcrumbs in the same location across pages
- **Mobile Considerations**: Consider showing fewer items or different styling on mobile
- **Performance**: For very long breadcrumb paths, implement collapsing with `maxItems`
