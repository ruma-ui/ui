### Editable `value` and `defaultValue`

Control the component's value either externally (controlled) or internally (uncontrolled).

```tsx
// Controlled
const [value, setValue] = useState("text");
<Editable value={value} onChange={setValue} />

// Uncontrolled
<Editable defaultValue="text" />
```

## Accessibility

The Editable component follows accessibility best practices:

- **Keyboard Navigation**: Full support for Tab, Enter, and Escape keys
- **Screen Reader Support**: Proper ARIA labels and live regions for dynamic content
- **Focus Management**: Clear focus indicators and logical focus flow
- **Semantic HTML**: Uses appropriate input elements with correct attributes

## Best Practices

### Do's ✅

- Use clear, descriptive placeholder text
- Provide visual feedback during editing states
- Consider using buttons for critical or long-form content
- Test keyboard navigation thoroughly

### Don'ts ❌

- Don't use for password or sensitive input fields
- Avoid very long text that would be hard to edit inline
- Don't rely solely on color to indicate editable state
