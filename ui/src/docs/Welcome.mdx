# Welcome to Ruma UI 🚀

**Ruma UI** is a modern, production-ready React component library and design ecosystem built with **TypeScript**, **Tailwind CSS v4**, and enterprise-grade CI/CD pipelines.

Whether you are building a fast prototype or scaling a complex enterprise application, Ruma UI provides beautifully crafted, accessible, and customizable components designed for seamless developer experience.

---

## ✨ Key Features

- **🎨 Modern Design Tokens**: Hand-crafted color palettes, glassmorphism support, dark mode readiness, and responsive layouts.
- **🧱 49+ Components**: Complete suite of interactive components ranging from basic inputs (`Button`, `Select`, `Input`) to advanced controls (`SortableList`, `Resizable`, `Video`).
- **🚀 Flexible Integration Options**:
  - **NPM Package (`@ruma-kit/ui`)**: Install pre-compiled, tree-shakeable React components for instant setup.
  - **CLI Add (`@ruma-kit/cli`)**: Copy component source code directly into your codebase for 100% control (shadcn-style workflow).
- **⚡ Built for Speed**: Minimal bundle overhead, full tree-shaking support, and performance-optimized rendering.
- **♿ Accessible First**: Built following WAI-ARIA authoring practices with keyboard navigation, focus trapping, and screen reader announcements.
- **📦 Full Monorepo Architecture**: Managed via **Nx** with automated releases, pre-release channels (`alpha`, `beta`, `rc`), and changeset tracking.

## ⚡ Quick Start Comparison

### Option A: NPM Package Integration

```bash
# Install the package
pnpm add @ruma-kit/ui

# Import stylesheet and components
import { Button, Card } from "@ruma-kit/ui";
import "@ruma-kit/ui/ui.css";
```

### Option B: CLI Direct Source Add

```bash
# Initialize Ruma UI configuration in your project
npx @ruma-kit/cli init

# Add components directly to your src/components directory
npx @ruma-kit/cli add button card modal toast
```
